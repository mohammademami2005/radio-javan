# 🎵 Radio Javan Music App (Next.js + TypeScript + Tailwind + Zustand + React Query)

This project is a **modern Music Streaming Web App** built using **Next.js**, **TypeScript**, **Tailwind CSS**, **React Query**, **Zustand**, and **Axios**. It features a smooth, responsive UI and supports both **SSR** and **CSR** rendering.
---

## 🌐 Demo (Live Demo)

🔗 [radio-javan.mohammademamiproject.ir](https://radio-javan.mohammademamiproject.ir/)

--- 

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎧 Music Player | Play / Pause / Next / Previous / Shuffle / Repeat |
| 🖼️ Dynamic UI | Modern, animated, responsive interface |
| 🎵 Tracks & Albums | Browse latest tracks, albums, and artists |
| 🔍 Search System | Search for tracks, albums, and artists |
| 🎚️ Global Player State | Managed with Zustand + persistence |
| ⚡ Fast Data Fetching | React Query with caching & auto-refetch |
| 📦 API Integration | REST API using Axios |
| 📱 Responsive Design | Fully optimized for mobile/tablet/desktop |
| 🧩 Modular Components | Clean architecture with reusable components |

---

## 🧭 Project Structure

```
src/app/                  # Next.js App Router pages                
 ├── components/          # UI components (Player, Sliders, Lists)
 ├── store/               # Zustand global state
 ├── services/            # Axios API handlers
 ├── provisers/           # providers config
 ├── types/               # TypeScript interfaces
 └── utils/               # Helper functions
```

## 💻 Run Locally

**Requirements:** Node.js 18+ / npm / pnpm / yarn

```bash
# Clone repository
git clone https://github.com/mohammademami2005/radio-javan
cd radio-javan

# Install dependencies
npm install

# Run development server
npm run dev
# http://localhost:3000
```

---

## ⚙️ Environment Variables
file: `.env.local`:

NEXT_PUBLIC_API_BASE_URL=https://example.com/api
